# IPL-Data-Analysis-using-Excel

## Analysis of IPL Dataset (2008 - 2018)

This project provides a comprehensive analytical deep-dive into the Indian Premier League (IPL) matches spanning from **2008 to 2018**. By leveraging advanced Excel techniques, this study transforms raw match data into a high-impact MIS Dashboard that tracks team performances, toss impacts, and individual player excellence.

The dataset captures every ball's drama across 11 seasons, detailing match locations, umpiring, and margin of victory.

---

### 📊 Key Insights & Findings

#### **Tournament Winners**

Between 2008 and 2018, the league saw dominant performances from core franchises:
* **Most Titles:** Mumbai Indians and Chennai Super Kings lead the pack with **3 titles** each.
* **Consistency:** Kolkata Knight Riders secured **2 titles**.
* **Historic Wins:** Rajasthan Royals (the inaugural champions), Deccan Chargers, and Sunrisers Hyderabad each hold **1 title**.


#### **The "Toss" Factor**

Data suggests that decision-making at the toss significantly influences match outcomes:
* **Fielding First:** Teams choosing to field first after winning the toss secured **32 wins**.
* **Batting First:** Teams choosing to bat first secured **26 wins**.


#### **Season Highlights (Inaugural Season)**

* **First Champions:** Rajasthan Royals.
* **Runner Up:** Chennai Super Kings.
* **Standout Performer:** Shane Watson was named **Player of the Series** for the 2008 season.

---

### 🛠️ Technical Skills Implemented

This project served as a comprehensive exercise in data engineering and visualization using **Microsoft Excel**:

* **Data Orchestration:** Cleaning and preparing raw datasets for dashboard integration.
* **Advanced Analytics:** Utilizing **Pivot Tables** and **Pivot Charts** to aggregate match statistics.
* **Interactive UI/UX:** Implementing **Slicers** to allow users to filter data dynamically.
* **Advanced Logic:** Using complex Excel formulas to calculate winning percentages and KPI metrics.
* **Visual Design:** Customizing shapes and icons to create a professional MIS (Management Information System) interface.

---

### 📂 Dataset Attributes

The analysis is built upon a robust schema including:

* **Temporal Data:** Year, Season, and Date.
* **Match Specifics:** Venue, City, Toss Winner, and Toss Decision.
* **Outcome Metrics:** Winner, Result, Win by Runs, and Win by Wickets.
* **Player Stats:** Player of the Match.
* **Officials:** Umpire 1 and Umpire 2.
